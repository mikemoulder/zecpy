## Reading this fairly

- **Scope.** This measures what request *content* reveals. It does not measure who is
  connecting: zingo-cli sends over the Nym mixnet by default, and ZecPy sends and syncs
  over Tor by default. Neither protection is visible to a loopback proxy, so both were
  measured without them.
- **Transparent support is a trade-off.** zingo-cli and zcash-devtool can receive to
  transparent addresses, and asking the server about those addresses
  (`GetTaddressTxids`, `GetAddressUtxosStream`) is how a light wallet finds such funds.
  ZecPy is shielded-only by design: it never issues these requests, and it cannot
  receive transparent funds.
- **Memos.** zingo-cli fetches received transactions by txid (`GetTransaction`), for example
  to read their memos. ZecPy does not read incoming memos; its invoices match payments by
  receiving address instead.
- **Counts depend on the chain.** zingo-cli's transparent lookups scale with its
  address gap limit; tree-state requests scale with the number of sync batches.

## Versions

- **ZecPy**: 0.1.0 (this repo)
- **zcash-devtool**: 0b3436b (its own sync loop on the librustzcash crates, transparent support on)
- **zingo-cli**: zingolib 625f617 (pepper-sync), built with its `nakednet-test-mode` measurement feature and without `nym`: by default zingo-cli sends over the Nym mixnet, which a loopback proxy cannot observe. Driven through its interactive prompt; each scenario is a new process

## What the identifying requests reveal

### ZecPy

No identifying requests.

### zcash-devtool

- `GetAddressUtxosStream`: queries transparent address UTXOs
- `GetTreeState`: tree state at 1044: an exact height tied to this wallet (its birthday, or where its last sync stopped) (and 2 similar)

### zingo-cli

- `GetTaddressTxids`: lists a transparent address's transactions: links the address to you
- `GetTransaction`: fetches one transaction by txid: the server learns it is yours
- `GetTreeState`: tree state at 1057: an exact height tied to this wallet (its birthday, or where its last sync stopped) (and 4 similar)
