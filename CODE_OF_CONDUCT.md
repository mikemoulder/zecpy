# Code of conduct

ZecPy follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and patient, assume good faith, welcome newcomers, criticise ideas
rather than people, and keep discussion about the work. Harassment, personal attacks and
publishing anyone's private information are not tolerated.

This applies in issues, pull requests, discussions and anywhere else the project is
represented.

To report a problem, use the private reporting link in [SECURITY.md](SECURITY.md) and say that
it concerns conduct. Reports are handled confidentially.
